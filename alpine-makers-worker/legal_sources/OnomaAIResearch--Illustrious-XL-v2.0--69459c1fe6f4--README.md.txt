## Illustrious XL v2.0-STABLE Model
Since Illustrious XL v2 utilized the cosine annealing learning rate schedule - the more stable checkpoint is in "last annealing phase."

Here, we upload slightly more stabilized checkpoint, which shows slightly different behavior, but generally more stable in generation phase.


![image/png](https://cdn-uploads.huggingface.co/production/uploads/63398de08f27255b6b50081a/knyLuPlgUHm1ylRQaxrnx.png)

The differences in the models are usually subtle - however should perform better in STABLE.

<Left - previous, Right - stable>

We plan to release separate optimized / derived checkpoint based on own research.
