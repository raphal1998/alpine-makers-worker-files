DOSSIER DOCUMENTAIRE ALPINE MAKERS — COPIE DE TEST

Ces fichiers sont des textes de licences, fiches auteurs, preuves de permissions
publiées et notices d'attribution. Les textes des éditeurs sont conservés dans
leur langue d'origine. Certains fichiers .txt contiennent le HTML officiel
intégral : les servir comme texte brut avec nosniff, jamais comme HTML exécuté.

INDEX.json répertorie les URL, dates de collecte et empreintes SHA-256.
legal_evidence.json relie ces documents aux 256 références du catalogue et
précise les éventuels manques. Les permissions Civitai sont des métadonnées
publiées rattachées au SHA-256 d'un artefact, pas un contrat signé avec Alpine.

Le présent dossier ne contient pas les poids IA ni l'ensemble des sources
correspondantes des binaires distribués. Les URL d'archives de code pointent
sur les révisions amont épinglées, sans certifier les modifications Alpine,
les scripts de construction, les environnements ou les autres dépendances.
Une fiche de catalogue auditée ne prouve pas la version installée sur chaque PC.

Collecteur reproductible depuis le dossier TEST :
  node scripts/collect_legal_evidence.mjs --offline

Le mode hors ligne reconstruit le dossier à partir des textes déjà vérifiés et
conserve leurs dates de collecte. Pour une actualisation réseau, fournir le
cache d'audit initial avec --audit-cache=<dossier> si disponible ; examiner le
diff et les erreurs, puis réviser la politique avant publication. Le collecteur
n'exécute pas les sources, ne télécharge aucun modèle et limite les textes à
650 Ko chacun et 7 Mo au total. Les erreurs de collecte restent signalées.

Ne jamais supprimer un avertissement commercial en substituant une licence
standard au contrat manquant. Les notices générées n'accordent aucun droit.
L'installation reste soumise aux conditions effectivement applicables et,
le cas échéant, aux autorisations écrites couvrant le contexte précis.
